# # Cisco Python Fundamentals - Code Samples & Scripts

This repository contains Python scripts and foundational projects built during my coursework in the Cisco Python Fundamentals course (Modules 1–4).

## 🚀 Key Concepts Covered

- **Module 1 & 2:** Variables, data types, standard input/output (`input()`, `print()`), basic type casting.
- **Module 3:** Control flow (`if`/`elif`/`else`), iterative loops (`while`, `for`), list operations, and slicing.
- **Module 4:** Custom functions, parameter handling, return statements, and data structures (`tuples`, `dictionaries`).

## 🛠️ Included Scripts

1. `data_formatting.py` – Takes unstructured user inputs, applies validation, and formats output.
2. `dictionary_lookup.py` – Demonstrates key-value mapping and data extraction using Python dictionaries.
3. `logic_flow.py` – Demonstrates conditional loops and list filtering logic.
